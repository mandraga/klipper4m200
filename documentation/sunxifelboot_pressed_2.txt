----------------------------------------------------------------------
We see that it loads second stage, and second stage looks for '2' pressed.
If it is, then it writes 0x5aa5a55a at 0x01f00108 and resets.
On reset, BOOT0 will run FEL mode because 0x01f00108 = 0x5aa5a55a.

So if we put here our u-boot mainline code, it won't work.
We can do something using u-boot memory commands:

```
=> mw.l 0x01f00108 0x5aa5a55a 1
=> md.l 0x01f00108 1
01f00108: 5aa5a55a                             Z..Z
=> reset
```

And we are in fel mode.
----------------------------------------------------------------------

We set:
```
setenv fel_mode 'mw.l 0x01f00108 0x5aa5a55a 1; reset'
```
And to go in fel mode:
```
run fel_mode
```
